# Assumptions ledger

Everything the prototype "knows" about the operation is labeled. FACT = stated on a public page or podcast transcript (cited in [research/A-solo-domain.md](research/A-solo-domain.md)). HYPOTHESIS = inferred from public material. ASSUMPTION = needed to build something demonstrable. UNKNOWN = deliberately not claimed. The people who do the work can correct this file in an afternoon; the code follows it, not the other way round.

## Data-quality notes worth keeping

Public pages disagree with each other in small ways (a street name, a zip code, a herd count, a job title). The synthetic seed does not reproduce those, but the reconciliation surface exists because that is what real records look like.
